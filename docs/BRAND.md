# Brand: Vanterra

## Name evaluation

The four candidates were checked with a web search on 2026-11-20. **This is not a trademark clearance**; a registry search by counsel would be needed before any commercial use.

| Candidate | Fit | Conflicts found | Verdict |
| --- | --- | --- | --- |
| NEXORIS | Distinctive; "nexus" suits connecting two domains | Several active companies of exactly that name, including two software firms (nexoris.in, nexoristech.com) and a Belgian company | Rejected: same name, same sector |
| PARALLAX | Strongest concept (two viewpoints give depth) | Common word; an existing cybersecurity product, "Sanctum Security Parallax"; other Parallax companies | Rejected: direct conflict in security, weak distinctiveness |
| SYNAPGRID | No exact match found | Close to SynapseGrid (a software library) and Synaptic Grid | Rejected: "synapse" reads as an AI gimmick, and "grid" narrows it to power |
| **VANTERRA** | *Vantage* + *terra*: a vantage point over the physical world. Calm, enterprise, not tied to one industry or to AI | No exact match found; nearest is **Avanterra** (data technology for asset management, Luxembourg), a different sector | **Chosen**, with Avanterra noted as the name to watch |

## Architecture of the name

| Element | Value |
| --- | --- |
| Product | **Vanterra** |
| Descriptor | Cyber-Physical Intelligence |
| Tagline | Investigate the physical and the digital together. |
| Positioning | Evidence-first investigation for industrial and critical-infrastructure incidents where process and OT-network events meet. |

## Identity

- **Mark:** a horizon line seen from a raised vantage point, drawn as two nested peaks. The outer stroke (neutral) is the physical plant; the inner stroke (azure) is the cyber layer. It works as a favicon at 16 px.
- **Wordmark:** "VANTERRA", uppercase, letter-spaced 0.26 em, weight 600, in the interface sans.
- **Typography:** Inter, falling back to Segoe UI or the system UI, for interface text; JetBrains Mono, falling back to Cascadia Mono or Consolas, for identifiers, times and labels. No display faces.

## Colour

Colour carries meaning only:

| Token | Value | Meaning |
| --- | --- | --- |
| `--bg` / `--panel-solid` | `#0a0d12` / `#0e131a` | Neutral graphite surfaces |
| `--cyan` (accent) | `#8fb4d9` | Desaturated steel for interface chrome and selection |
| `--amber` / `--orange` / `--red` | `#e5b94e` / `#ec8a3c` / `#e5484d` | Physical severity: advisory, warning, critical |
| `--cyber` | `#5e9bff` | Cyber domain: events, OT devices, control links |
| `--ai` | `#b48cff` | AI-generated, advisory content |
| `--ok` | `#4cb782` | Observed criteria; operator-confirmed |

Dashed borders mean "possible / not established"; solid borders mean "supported". Bloom in the 3D scene was reduced and the neon cyan replaced, so glow marks state, not decoration.

## Terminology

| Term | Meaning in the product |
| --- | --- |
| Observation | A measurement or security record as received |
| Detection / anomaly / cyber event | An observation that satisfied a rule; the rule and its numbers are shown |
| Correlated | Linked through a declared relationship. Linked is not the same as caused |
| Hypothesis | A possible physical explanation, scored on evidence for and against (not a probability) |
| Cyber-physical assessment | The deterministic verdict on what the cyber evidence supports about a physical incident |
| Case | A group of related cyber events |
| Confirmed | Verified by a person. Nothing automated can set it |
